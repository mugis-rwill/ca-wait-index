Task 3 · CIHI hip & knee replacement · 2020–2025

Matched Pairs Register

Every pair the rule produced. Nothing was removed for being unremarkable, and nothing is ordered by the size of its gap.

The rule

fixed before results
Both provinces' volume within 5% of each other, same procedure, same year. Both using the same reporting window and same provenance type.

Volume test

|vola − volb| / max(vola, volb) ≤ 0.05
The rule as written names no denominator. max() is the strictest of the three candidates and is symmetric, so neither province is the reference.

Denominator sensitivity

max, mean and min all return the same 18 pair-years. The ambiguity turned out to be immaterial — nothing rests on that judgment call.

Reporting window

April–September, all ten provinces, all six years. Bare-year CIHI rows only; no fiscal-year or October–March rows were used.

Provenance

Provincial ministry submission for all ten. CIHI calculates only Hip Fracture Repair itself, and that indicator is not used here.

What those two clauses filtered

Nothing. Window and provenance are uniform across all ten provinces, so all 45 pairs satisfy them by construction. The volume test is the only binding constraint. Both are still enforced in code.

Post-hoc filtering

None. Rows below are sorted by procedure and pair name. Not by gap size, and not by anything else chosen after the results were seen.

All surviving pair-years

the result

Province A is the alphabetically first of the pair, so the direction of a gap is always read the same way and cannot flip between years by accident. The bar scales the absolute P90 gap against the largest in the set (207 days).

How often each pair survives

persistence
No pair survives all six years. Volumes that match one year routinely diverge the next, so the brief's "direction of the gap in each of the six years" cannot be answered inside the rule. The best any pair manages is three. The six-year view below fills the remaining years in, flagged, so direction can be read across the window without implying the rule was met.

Six-year detail

context, flagged

Every surviving pair across all six years. Only rows marked “rule met” passed the volume test — the others are context for reading the direction of the gap and must not be quoted as matched comparisons.

All 72 pair-years

No confidence intervals. CIHI receives aggregate percentiles submitted by provincial ministries, not case-level records, and publishes no intervals of its own — so there is no sampling distribution to draw one from. None were manufactured.
